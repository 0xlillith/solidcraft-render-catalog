## Updating credits

Edit `credits.json` or the preserved source metadata in the resource directory, then run `python tools/library/catalog.py build`. `python tools/library/catalog.py check` verifies generated output. Generated credit files must not be edited by hand. Full source publications are not automatically copied into the library.
