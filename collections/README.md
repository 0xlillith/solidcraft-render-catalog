[Complete resource index](../INDEX.md)

These editable selections group existing assets without creating a pack, coupling versions or downloading payloads. A resource may appear in several collections.

- [Chemical elements and illustrative looks](element-studies.md): **272** resources. Scientific element identities and separate illustrative surface looks. Neither implies a condition-qualified engineering grade or measured optics.
- [Studios and render presets](studio-studies.md): **59** resources. Studio resources and rendering settings, with each representation's application behavior and evidence kept explicit.
- [Wood appearances and physical references](wood-studies.md): **477** resources. Browse wood appearance studies alongside their separately qualified physical references. Selecting an appearance does not assign physical properties.
