# Per-extra quality utilities

Use `../improve.py` for an independently selected extra. Numerical transforms are
original authored operations and never reassign physical-reference properties.
`tools/native_mcp.py` starts an isolated native process; no GUI document is replaced.
`tools/native_matrix.py` is a bounded coupon/evidence runner, not a pack builder or
whole-material optical certification. Historical producers/receipts are separate.

Tests: `python -m unittest discover -s tools/extras/quality/tests -v`.
No network call, release publish or upstream modification is part of these tools.
